# TikTok: границы интеграции

Дата попытки проверки: 20 октября 2026 года. В этой облачной среде HTTPS-запросы
к `developers.tiktok.com` отклонены прокси: `Tunnel connection failed: 403 Forbidden`.
Текущую редакцию документации и доступ конкретного приложения подтвердить не удалось.
Ниже приведены официальные адреса для повторной проверки, а не заявление о выданных разрешениях.

| Источник | Назначение и решение в этом проекте |
|---|---|
| [Research API](https://developers.tiktok.com/doc/research-api-get-started) | Исследовательский доступ требует отдельного одобрения и проверки допустимости. Не используется как источник коммерческих заданий. |
| [Query Videos](https://developers.tiktok.com/doc/research-api-specs-query-videos) | Не подключён: доступ и разрешённость этого сценария не подтверждены. |
| [Display API](https://developers.tiktok.com/doc/display-api-overview) | Не трактуется как глобальный поиск по чужим роликам; OAuth-интеграция не реализована. |
| [Content Posting API](https://developers.tiktok.com/doc/content-posting-api-get-started) | Не используется для комментариев под чужими видео. Автопубликация комментариев в программе отсутствует. |
| [Embed videos](https://developers.tiktok.com/doc/embed-videos) | Реализован отдельный запрос `GET https://www.tiktok.com/oembed?url=...` для известной прямой ссылки. Получаем только возвращённые описание и автора; дата не выдумывается. |
| [Rate limits](https://developers.tiktok.com/doc/tiktok-api-v2-rate-limit) | Текущие квоты не подтверждены. oEmbed 429 останавливает операцию; обходов и бесконечных повторов нет. |

Поиск в приложении означает фильтрацию **импортированных** ссылок и метаданных по
включённым хештегам либо ключевым словам. Глобального поиска TikTok нет. Если метаданные
неизвестны, пользователь открывает видео и заполняет их вручную. Дата из ID не вычисляется.
Видео без проверенной даты не допускается к подготовке и подтверждению публикации.
Введённые и импортированные метаданные — свидетельство пользователя, не проверка TikTok.

Для автоматической публикации текстовых комментариев, комментариев с изображениями и
лайков разрешённый публичный метод для данного приложения не подтверждён. Поэтому
проект не эмулирует браузер, не использует приватные endpoint, cookies, CAPTCHA-сервисы
или прокси для обхода ограничений. Пользователь самостоятельно публикует подготовленный
текст и оригинал картинки, после чего подтверждает отдельные пункты чек-листа.

Цель «6 публикаций в минуту» не гарантируется: здесь настраивается только частота
**подготовки**. Фактические публикации выполняет человек. Отчёты RubUP и начисления
также подтверждаются вручную; API RubUP в проект не придуман.

Официальные справочники остальных интеграций:

- [OpenAI Responses API](https://platform.openai.com/docs/api-reference/responses).
- [OpenAI pricing](https://openai.com/api/pricing/) — тарифы вводятся вручную; цены не зашиты.
- [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage).
- [Telegram getMe](https://core.telegram.org/bots/api#getme).

Сетевые интеграции проверены локальными HTTP-моками. Запросы к реальным аккаунтам,
платная генерация и отправка сообщений при разработке не выполнялись.
