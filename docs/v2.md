# Что изменилось в RubUP Automation 2.0

Приложение обновлено поверх существующих сервисов, SQLite и истории.

- Пять разделов вместо перегруженной стартовой таблицы. На Главной — ссылка,
  одна основная кнопка и три показателя.
- Готовый комментарий, проверка требований и действия собраны в карточке результата.
  Подробные поля, отчёты и экспорт сохранены в дополнительных действиях.
- Добавлено безопасное раскрытие коротких HTTPS-ссылок `vt.tiktok.com`/`vm.tiktok.com`.
  Каждый переход проверяется; произвольные сайты, локальные адреса и бесконечные цепочки запрещены.
- Неизвестная дата допускает предварительный комментарий, но не подтверждение
  подходящего оплачиваемого задания. Недостающие данные проверяются отдельно.
- Настройка OpenAI и Telegram выполняется в приложении. Доступные модели берутся
  из реального ответа API. Неизвестные тарифы не выдаются за нулевую цену.
- Добавлены встроенная помощь, мастер из пяти шагов и бесплатная локальная демонстрация.
- Оригиналы картинок, история, защита от повторов и ручное подтверждение публикации сохранены.
- Добавлен `install.bat` для разовой установки. `start.bat` запускает GUI без постоянной
  консоли; сценарии используют кавычки для путей с пробелами и русскими буквами.

Новые признаки предварительного черновика хранятся в существующем JSON-чек-листе.
Схема SQLite не сбрасывается; существующая история и уникальные ограничения сохраняются.
Мастер использует отдельный небольшой файл состояния. Ключи на Windows защищаются DPAPI
текущего пользователя; прежний `.env` остаётся совместимым.

Демонстрация использует только отмеченные тестовые данные и отдельное состояние.
Она не отправляет Telegram, не вызывает платные API и не меняет рабочую историю.
Реальные публикации в TikTok и отчёты по-прежнему выполняет и подтверждает пользователь.
Сведения не выдумываются, защитные механизмы TikTok не обходятся.

Функциональные проверки запускаются в Linux с HTTP-моками и offscreen GUI.
Запуск на Windows 10/11 и готовый EXE требуют отдельной проверки на Windows.
Итоговые результаты тестов приведены в [validation.md](validation.md).
