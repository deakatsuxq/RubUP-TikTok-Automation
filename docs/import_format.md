# Импорт и проверка видео

Программа не выполняет глобальный обход TikTok по хештегам. Откройте TikTok самостоятельно, найдите ролики по включённым хештегам и перенесите **прямые** ссылки в программу. Короткие ссылки `vm.tiktok.com`, ссылки профилей и ссылки других сайтов не принимаются: сначала откройте ролик в браузере и скопируйте полный адрес.

Ниже показаны шаблоны адресов и метаданных, **не найденные реальные ролики**. Замените `your_author` и `123456789` своими значениями. URL должен иметь вид:

```text
https://www.tiktok.com/@your_author/video/123456789
```

Параметры отслеживания после `?` автоматически удаляются; ID используется для удаления дубликатов. Один и тот же ID не импортируется повторно даже при другом написании автора в адресе. Уже сохранённые метаданные повторный импорт не перезаписывает — изменяйте их в карточке задачи.

## TXT: по одной ссылке в строке

```text
https://www.tiktok.com/@your_author/video/123456789
https://www.tiktok.com/@another_author/video/987654321
```

Ссылки без даты отправляются на ручную проверку. Программа **не определяет дату по ID видео** и не считает дату импорта датой публикации.

## CSV: ссылки с метаданными

Сохраните файл в UTF-8; UTF-8 с BOM также поддерживается. Разделитель — запятая, точка с запятой или табуляция. Строка заголовков обязательна; обязательный столбец — `url`. Пример шаблона:

```csv
url,author,description,hashtags,published_at,query,category
https://www.tiktok.com/@your_author/video/123456789,your_author,Ваше проверенное описание #cs2,cs2,2026-05-01,cs2,CS2
```

Поля `hashtags`, `description`, `published_at`, `author`, `query`, `category` необязательны. Если текст содержит запятую, заключите поле в двойные кавычки. Несколько хештегов в `hashtags` разделяются пробелом, запятой или точкой с запятой; начальный `#` необязателен. Хештеги из описания также учитываются.

## JSON: список объектов или ссылок

```json
[
  {
    "url": "https://www.tiktok.com/@your_author/video/123456789",
    "author": "your_author",
    "description": "Ваше проверенное описание #cs2",
    "hashtags": ["cs2"],
    "published_at": "2026-05-01",
    "query": "cs2",
    "category": "CS2"
  }
]
```

Также принимаются `{"videos": [...]}` и список строк URL. Поле `date` поддерживается как синоним `published_at`. При наличии поля `video_id` оно должно совпадать с ID в адресе. Метка `is_test` из файла не превращает импорт в тестовый: в рабочей базе импорт всегда рабочий; для экспериментов запускайте отдельный dry-run.

## Происхождение и проверка метаданных

Все сведения в CSV/JSON вводит пользователь. Программа проверяет формат и фильтры, но импорт **не подтверждает подлинность** указанной даты, описания или автора. Перед импортом проверьте их на странице реального ролика. Изменение метаданных через карточку сохраняется в локальном журнале как ручное действие.

Опциональная кнопка получения метаданных обращается к публичному TikTok oEmbed для уже известной ссылки. Этот источник может вернуть название и автора; доступ зависит от TikTok, региона и сети. Из oEmbed не извлекается дата публикации. Отсутствующая, некорректная или будущая дата требует ручной проверки. Ошибка oEmbed не заменяется выдуманными значениями. При HTTP 429 получение прекращается.

Для автоматической подготовки должны совпасть дата (`2026-05-01` или позже по умолчанию) и хотя бы один включённый хештег либо ключевое слово. Отключённые хештеги исключаются из сопоставления; отдельное совпадение ключевого слова при этом по-прежнему допускает ролик. `#cs2clips` не совпадает с `#cs2`. При отсутствии описания/хештегов задача также требует ручной проверки.

Лимиты импорта: 10 МБ на файл и 10 000 записей за вызов. Неверные строки учитываются как отклонённые, дубликаты — отдельно. Файл не скачивает видео и не выполняет публикаций. История реальных данных и тестовая база dry-run разделены.
