# Архив совместимости RubUP 2.0–3.0

Это сохранённые исходники прежней программы, включая прежнюю генерацию ИИ
и настройки расходов. RubUP Automation 4.0 их не импортирует, не запускает
и не включает в EXE. Они нужны только для неизменённых исторических тестов.
Путь к архиву добавляет исключительно `tests/conftest.py` при запуске pytest.

Рабочая версия 3.0 целиком сохранена в Git-ветках `backup-v3` и `rubup-v3`.
Рабочая версия 2.0 сохранена в `backup-v2`. Пользовательские базы, ключи,
настройки и браузерные профили сюда не копируются.
